PYTHON FUNCTIONS — 5 PRACTICE QUESTIONS

1. *args — Sum and Average

Create a function calculate() that accepts any number of numerical arguments using *args.

The function should:
- Calculate the total
- Calculate the average
- Print both values

Example:
calculate(10, 20, 30, 40)

Expected Output:
Total: 100
Average: 25.0


2. **kwargs — Student Information

Create a function student_details() that accepts any number of keyword arguments using **kwargs.

Print each key and value in the following format:

Name : Harsh
Age : 22
Course : B.Tech
City : Ahmedabad

Test the function with at least 4 different pieces of information.


3. Default Arguments — Electricity Bill

Create a function:

def calculate_bill(units=100, rate=8):

Calculate:

Bill = units × rate

Call the function in all three ways:

calculate_bill()
calculate_bill(200)
calculate_bill(300, 10)

Display the bill for each call.


4. Positional + Keyword Arguments — Employee

Create a function:

def employee(name, department, salary):

The function should print:

Name       : Harsh
Department : IT
Salary     : 35000

Call the function using:

1. Positional arguments
2. Keyword arguments
3. Mixed positional and keyword arguments

Example:

employee("Harsh", "IT", 35000)

employee(
    name="Harsh",
    department="IT",
    salary=35000
)


5. *args + **kwargs — Product Details

Create a function:

def product(*prices, **details):

The function should:

- Accept any number of product prices using *prices
- Accept product information using **details
- Calculate the total price
- Display all product details
- Display the total price

Example:

product(
    500, 200, 300,
    name="Keyboard",
    brand="Ant Esports",
    category="Electronics"
)

Expected Output:

Name     : Keyboard
Brand    : Ant Esports
Category : Electronics

Prices   : (500, 200, 300)
Total    : 1000
